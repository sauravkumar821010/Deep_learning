Section 1

What is a Neuron?

A neuron combines weighted inputs, adds a bias, and passes the result through an activation function to produce an output.

Formula: output = activation(Σ(xᵢ · wᵢ) + b)

Section 2

MLP Architecture

A multi-layer perceptron stacks neurons into layers so the network can learn increasingly rich representations from input to output.

Section 3

Forward Propagation

During the forward pass, features move from left to right. Each layer computes a weighted sum and activation before handing the signal to the next layer.

Input X
→
Linear Z = W·X + b
→
Activation A = f(Z)
→
Prediction ŷ

Step 1

Combine inputs and learned parameters with matrix multiplication.

Z = W · X + b

Step 2

Apply a non-linear transformation so the network can learn complex patterns.

A = activation(Z)

Step 3

Repeat the process layer by layer until the final output is produced.

X → Hidden → Hidden → Output

Section 4

Backpropagation

Backpropagation moves from right to left, measuring error and using the chain rule to compute how each weight contributed to the loss.

Loss L(ŷ, y)
←
Output Gradients ∂L/∂A
←
Chain Rule ∂L/∂Z · ∂Z/∂W
←
Update Weights W = W - α·∂L/∂W

Loss

Measure how far predictions are from the target.

MSE = (1/n) Σ(y - ŷ)²

Gradient

Propagate sensitivity backward to learn the slope for each parameter.

∂L/∂W = ∂L/∂A · ∂A/∂Z · ∂Z/∂W

Learning Rule

Use the gradient and learning rate α to reduce loss over time.

W = W - α · ∂L/∂W

Section 5

Activation Functions

Activation functions shape the signal passing through a network and determine what kind of behavior each layer can express.

Sigmoid

σ(x) = 1 / (1 + e-x)

Use case: binary output probabilities and classic hidden layers.

ReLU

ReLU(x) = max(0, x)

Use case: deep hidden layers because it is simple and efficient.

Tanh

tanh(x) = (ex - e-x) / (ex + e-x)

Use case: centered hidden activations with outputs in [-1, 1].

Softmax

softmax(zᵢ) = ezᵢ / Σezⱼ

Use case: multi-class classification probabilities across output neurons.
